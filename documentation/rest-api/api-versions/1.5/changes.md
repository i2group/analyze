# Changelog for i2 Analyze REST API 1.5

Version 1.5 contains minor changes to the i2 Analyze REST API.

## Added

At this release, the following public endpoints are new and fully supported in the i2 Analyze REST API:

- [`core/versioninfo`](https://docs.i2group.com/analyze/4.4.6/public-rest-api.html#get-/api/v1/core/versioninfo)

    This GET endpoint is for retrieving version information for the product.\
    **Note:** Requests to this endpoint do not require authentication.
